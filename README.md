# WIG3003-PhotoEditor
A JavaFX-based application designed for comprehensive photo management, digital image processing, and multimedia synthesis.

## Email setup

Copy `email-config.example.properties` to `email-config.properties` in the project root and fill in your own sender email and app password.

You can also use environment variables instead:

- `PHOTO_EDITOR_SENDER_EMAIL`
- `PHOTO_EDITOR_APP_PASSWORD`
- `PHOTO_EDITOR_SMTP_HOST`
- `PHOTO_EDITOR_SMTP_PORT`
